## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um portfólio pessoal para apresentar meu perfil profissional, minha formação, minhas habilidades e alguns projetos realizados durante meu aprendizado em Desenvolvimento de Sistemas.

O objetivo é reunir minhas informações em um único site, utilizando HTML, CSS e Bootstrap, com uma apresentação organizada, responsiva e personalizada.

## ⚙️ Funcionamento do projeto

O portfólio foi organizado em diferentes seções, permitindo que os visitantes naveguem pelas informações utilizando o menu principal.

As seções disponíveis são:

- **Perfil:** apresenta minha área de interesse, formação, localização, objetivo profissional e tecnologias que estou estudando.
- **Projetos:** apresenta alguns trabalhos e atividades desenvolvidos durante meu aprendizado.
- **Contato:** disponibiliza links para minhas plataformas profissionais e uma opção de contato por e-mail.

Também foi utilizado um Carousel do Bootstrap para apresentar imagens em slides na parte inicial do site.

O layout utiliza recursos do Bootstrap para organizar os elementos e adaptar a apresentação a diferentes tamanhos de tela.

## ✨ Recurso novo adicionado

**Efeito luminoso nos cards da seção de projetos.**

Como recurso adicional ao modelo desenvolvido em aula, implementei um efeito visual nos cartões da seção de projetos.

Quando o visitante posiciona o cursor sobre um dos cards, ele recebe um brilho roxo ao redor e aumenta levemente de tamanho, criando uma interação visual.

## 💡 Como o recurso foi implementado

O efeito foi desenvolvido utilizando CSS, por meio de uma classe personalizada chamada `.card-projeto`.

Foram utilizadas as seguintes propriedades:

- `transition`: permite que a mudança visual aconteça suavemente.
- `:hover`: ativa o efeito quando o cursor passa sobre o elemento.
- `box-shadow`: cria a sombra luminosa ao redor do card.
- `transform: scale(1.03)`: aumenta levemente o tamanho do cartão.

A implementação foi feita no CSS.

## 🤖 Utilização de Inteligência Artificial

Durante o desenvolvimento do projeto, utilizei ferramentas de Inteligência Artificial, incluindo o ChatGPT, como apoio para buscar inspirações visuais, conhecer possibilidades de personalização e esclarecer dúvidas sobre HTML, CSS e Bootstrap.

A IA também me auxiliou a compreender algumas propriedades CSS e a identificar possíveis problemas no código.

As sugestões foram analisadas e adaptadas ao projeto conforme minhas necessidades. A implementação e personalização do portfólio fizeram parte do meu processo de aprendizagem.
